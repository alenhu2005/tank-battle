# 坦克對戰

手機可玩的線上即時坦克對戰。每位玩家帶一台**用自己寫的代碼控制的電腦隊友**上場。玩家可以先跟自己的 AI 助手討論，再把寫好的代碼貼進遊戲。

## 玩法

- 輸入暱稱、建立房間，把 4 位數房號（或「分享」連結）給朋友，最多 6 人。
- 房主可以加入「電腦隊伍」湊人數或自己練習。
- 每位玩家有一台自己操作的坦克（3 條命）和一台代碼控制的電腦坦克（1 條命）。
- 沒有友軍傷害，但所有坦克之間都有碰撞。
- 每局結束後有調整時間：可以看自己電腦的錯誤和 `console.log`、修改代碼、換職業。房主決定總共打幾局。

### 模式（房主在大廳設定）

| 設定 | 說明 |
|---|---|
| 大亂鬥 | 每位玩家和自己的電腦一隊 |
| 陣營戰 | 紅藍兩軍 |
| 組隊 | 玩家自選 1～6 號隊伍，同號就是隊友 |
| 純代碼對戰 | 玩家不下場，每人只派一台電腦坦克，大家一起看 |
| 電腦也有職業 | 電腦坦克也可以選職業、用技能（預設關閉） |
| 血量系統 | 每條命有血條，子彈依職業扣血（預設開啟；關掉就是一發一條命的經典玩法） |
| 特殊地形 | 🛢️ 油桶（打到會爆炸、會連鎖）、✚ 補血站、🌀 傳送門（預設開啟） |
| 縮圈 | 時間過 4 成後安全區往中央縮，圈外持續扣血（只在生存、佔點） |
| 近距離鏡頭 | 玩家畫面只看得到自己周圍，看不到全圖；搭配迷霧更刺激（電腦不受影響） |
| 基地模式 | 每隊一座基地，被打爆就整隊出局 |
| 迷霧 | 玩家只看得到自己周圍；電腦不受影響 |
| 牆壁打不破 | 磚牆變成打不破，基地圍牆會留缺口 |
| 場地道具 | 每 10 秒刷新一個道具，共 22 種（預設開啟） |
| 子彈反彈 | 子彈撞到鋼牆和邊界會反彈，最多 2 次 |

房主在遊戲中可以按右上角的 ⏹ 兩下，強制結束這一局（算平手）。

### 道具

道具一覽、圖示和效果都定義在 `server/constants.js` 的 `ITEM_TYPES`，大廳設定裡也有說明。撿到時畫面上方會顯示這個道具的功能。

模式和開關可以自由組合，例如「組隊＋基地＋迷霧」。

### 職業

預設只有玩家坦克有職業，電腦是標準規格、沒有技能。房主打開「電腦也有職業」後，每位玩家可以在大廳的「我的電腦職業」幫自己的電腦另外選一個職業（電腦隊伍隨機），電腦就會有那個職業的數值和技能（代碼回傳 `skill: true`）。

玩家的射速平均約是標準電腦的 2 倍。標準電腦：移速 3、冷卻 1.0 秒、同時 1 顆子彈、彈速 6。死掉後 5 秒重生（剛好看完死亡重播）。

| 職業 | 移速 | 開火冷卻 | 同時子彈 | 彈速 | 特性 | 技能 |
|---|---|---|---|---|---|---|
| 突擊 | 3 | 0.43 秒 | 3 | 6 | 連射型，射最快 | ⏩ 衝刺（6 秒）：0.5 秒內移動速度 ×2.5 |
| 重裝 | 2.1 | 0.6 秒 | 2 | 5.25 | 每條命要被打 2 下 | 🧱 護盾牆（12 秒）：在正前方立起 3 格鋼牆，5 秒後消失 |
| 偵察 | 4.2 | 0.5 秒 | 2 | 6 | 移動最快；迷霧視野最大，看得穿草叢 | 🌫️ 煙霧（12 秒）：放出 5 秒的煙霧，裡面的坦克敵人看不到（玩家和電腦都看不到） |
| 狙擊 | 2.7 | 0.67 秒 | 1 | 10.5 | 子彈最快，迷霧視野較大 | 🎯 蓄力射擊（8 秒）：下一發（5 秒內）速度 ×1.8、撞到敵方子彈不會被抵消、會穿過第一台坦克 |
| 爆破 | 2.85 | 0.6 秒 | 1 | 6 | 子彈爆炸：炸毀 3×3 磚牆、波及周圍敵人 | 🧨 地雷（7 秒）：在腳下放地雷（只有自己隊看得到），1 秒後啟動，敵人碰到就爆炸；最多 3 個 |
| 工兵 | 2.7 | 0.67 秒 | 1 | 6.75 | 防守型 | 🔧 築牆（5 秒）：在正前方蓋一塊磚牆；在自家基地旁使用時改成修補並加固基地圍牆 |
| 護士 | 2.85 | 0.6 秒 | 2 | 6 | 支援型，火力弱 | 💉 治療（10 秒）：治療自己和 3 格內的隊友 40% 血量（經典模式改成補滿耐久＋1.5 秒護盾） |

### 血量系統（預設開啟）

每條命有血條，被打中扣血，扣到 0 才算死一次。血量 = 房主設定的血量（進階規則裡玩家／電腦分開，預設 100）× 職業倍率。「自動回血」預設關閉（只有偵察會自己回血，其他靠護士和醫療包）；房主打開後 5 秒沒受傷就會慢慢回血。道具多了「🩹 醫療包」。

| 職業 | 血量 | 每發傷害 | 血量特色 |
|---|---|---|---|
| 突擊 | 100 | 25 | 連擊：1 秒內連續打中同一個敵人，每發多 5（最多多 15） |
| 重裝 | 140 | 32 | 爆炸和地雷傷害減半 |
| 偵察 | 90 | 30 | 沒受傷 3 秒就會自己回血（沒開自動回血也會；開了的話速度 2 倍） |
| 狙擊 | 90 | 45～80 | 距離越遠傷害越高（蓄力再 ×1.5） |
| 爆破 | 110 | 38 | 爆炸波及周圍敵人 23 |
| 工兵 | 135 | 40 | 每次成功築牆回自己 20% 血 |
| 護士 | 100 | 24 | 身邊 3 格內的隊友交戰中也會持續回血（每秒 4%） |
| 電腦（沒有職業） | 100 | 35 | |

數值在 `server/constants.js` 的 `HP`；`HP=1 node --no-node-snapshot test/balance.js 80` 會用血量系統跑平衡模擬。每個職業的坦克外型都不一樣（雙砲管、裝甲裙板、尖頭、長砲管加瞄準鏡、警示條紋、推土鏟、紅十字），一眼就看得出對手是什麼職業。

所有數值都在 `server/constants.js`；整體節奏用最上面的 MOVE_SCALE（移速）、BULLET_SCALE（彈速）、FIRE_SCALE（冷卻）三個倍率調整，實際玩過之後可以再調。`node --no-node-snapshot test/balance.js 100` 會用範例 AI 跑一次平衡模擬。

### 電腦代碼

遊戲內「我的電腦代碼 → 規格」可以一鍵複製完整規格，貼給 AI 助手。規格只寫必要的事實（資料格式、地形、規則），策略留給玩家自己設計。代碼送出前，伺服器會用真正的遊戲引擎跑幾場測試對戰，確認能正常執行才會啟用。玩家代碼在隔離的 V8 沙盒（isolated-vm）裡執行，碰不到伺服器，無窮迴圈也會被逾時擋下。

## 打怪（PvE）

大廳「目標」選「打怪」，所有玩家同一隊。固定使用血量系統。

| 模式 | 內容 |
|---|---|
| 戰役 | 3 章 × 3 關，每章最後是 Boss；通關依「通關／無人陣亡／標準時間內」給 1～3 星 |
| 無盡 | 波次無上限，每 5 波一隻 Boss（鋼鐵堡壘、毒霧女王輪流），每週排行 |
| 每週挑戰 | 每週固定關卡＋2 個詞綴（殉爆、迅捷、菁英、黑暗、玻璃砲、斷補），比通關時間 |

難度：簡單、普通、困難、煉獄（血量、傷害、精英機率、彈速遞增；困難以上不回命）。怪物數量與 Boss 血量依我方坦克總數縮放。

| 關卡 | 目標 |
|---|---|
| 1-1 初次接觸 | 撐過 4 波 |
| 1-2 砲台陣地 | 摧毀 3 座據點 |
| 1-3 **鋼鐵堡壘** | 四座砲塔可個別擊毀；60% 旋轉掃射＋召喚；25% 衝撞 |
| 2-1 守護核心 | 保護中央核心 3 分鐘 |
| 2-2 救援 | 護送友軍坦克到撤離點（附近有我方才會前進） |
| 2-3 **毒霧女王** | 飛行、毒霧；60% 分身（真身有影子）；25% 全場毒霧只剩移動的安全島 |
| 3-1 斷電 | 依序啟動 4 座發電機 |
| 3-2 **雷霆列車** | 只有車頭會受傷，路口丟炸彈，繞 4 圈撞毀核心前擊毀 |
| 3-3 **機械巨像** | 雷射（重裝與磚牆可擋）、砲台；70% 地圖崩塌；40% 起核心每 15 秒開放一次 |

- **怪物 10 種**：爬蟲、衝鋒者、砲台、狙擊蟲、自爆蟲、護盾兵、治療者、召喚師、潛伏者、工程兵。精英詞綴 6 種：狂暴、堅韌、分裂、寒冰、反射、傳染。
- **預警**：Boss 招式、狙擊、轟炸出手前，地面先出現紅線或紅圈。
- **強化卡**：每波結束三選一（31 張，普通／稀有／傳說，含職業專屬卡）；擊殺掉落零件，可買補命、修核心、重抽、復活隊友。
- **紀錄**：首頁「打怪圖鑑・成就・排行榜」：遇過的怪物圖鑑、20 個成就、各關星級、無盡與每週排行。通關章節解鎖坦克塗裝。
- **電腦代碼**：規格 v5 加入打怪欄位（預警區、Boss、目標、抽卡 pick／buy）；範例新增「打怪專用」。

## 其他功能

- **新手教學**、**代碼練習場**（單人、純代碼、可快轉 1×／2×／4×）、**代碼擂台**（每週排行榜，提交後立刻和其他參賽者對戰，Elo 計分）：都在首頁。
- **遊戲目標**：生存、佔點、搶旗、護送（推礦車，每局交換攻守）、打怪（見下方）。佔點、搶旗、護送可以無限重生。
- **進階規則**（房主）：玩家／電腦命數分開設定（可設無限）、移速／彈速／冷卻倍率、重生時間、道具頻率；玩家列表點「命±」可以幫個別玩家讓分。
- **職業技能**：每個職業一個主動技能（按鈕在開火鍵旁，鍵盤 K 或左 Shift），電腦代碼回傳 skill: true 也能用。
- **連線**：畫面左上角顯示延遲；伺服器有延遲補償（最多倒帶 0.2 秒），畫面上打中就算打中。
- **觀戰**：死掉後點「看隊友」可以切換鏡頭跟著隊友或自己的電腦。
- **殘血警示**：血量低於 3 成時畫面四周泛紅並震動。
- **電腦表現分析**：賽後列出發呆、卡住、每次陣亡是否躲得掉、命中率，並可一鍵複製給 AI。
- **擂台重播**：參加代碼擂台後可以看每一場對戰的重播。
- **地圖**：隨機、迷宮、開闊、河流、森林、堡壘，或用地圖編輯器自己畫。
- **操作**：自己的坦克用本機預測移動（按下就動，不等網路），有瞄準輔助線（會畫出反彈路線）。設定裡可以調搖桿和按鈕大小、透明度、左手模式、音效、震動。
- **賽後**：每局 MVP、擊殺、助攻、傷害、治療量、命中率、閃避次數；整局重播（可快轉、拖曳、分享連結、下載重播檔）。
- **內建電腦**故意做得很笨（不會尋路、不會閃子彈、亂開槍），沒交代碼的玩家、電腦隊伍和怪物都用它，讓自己寫的代碼有發揮空間。
- **規格版本**：規格開頭有版本號和最近更新，送出代碼時會提醒「這份代碼可能沒用到的新功能」（血量、技能、縮圈、新地形），可一鍵複製「請 AI 更新」的指令。
- **練習場選對手**：房主點電腦隊伍的 🧠 標籤可以換打法（白痴、標準、守門員、刺客、保鑣、我的代碼、我的上一版）。
- **安裝成 App**：首頁的「安裝成 App」（Android）或 Safari「加入主畫面」（iPhone），全螢幕開啟。
- **電腦代碼**：「複製 AI 指令」只給規則、不附範例；另有四種現成打法（標準、守門員、刺客、保鑣）可以直接選用或當作範本；代碼可以用 `debug.line / circle / text / path` 把想法畫在畫面上（只有自己看得到）。

## 在自己電腦上執行

需要 Node.js 20 以上。

```bash
npm install
npm start
```

打開 http://localhost:8080 。同一個 Wi-Fi 的手機可以用 `http://電腦IP:8080` 連進來。

測試：`npm test`

## 部署到 Google Cloud Run（用 Google AI Pro 的免費額度）

Google AI Pro 訂閱附有每月 10 美元的 Google Cloud 額度，Cloud Run 本身也有每月免費額度。以「沒什麼人玩」的用量來說，通常不會花到錢。

[![在 Cloud Shell 開啟](https://gstatic.com/cloudssh/images/open-btn.svg)](https://shell.cloud.google.com/cloudshell/editor?cloudshell_git_repo=https%3A%2F%2Fgithub.com%2Falenhu2005%2Ftank-battle&cloudshell_tutorial=TUTORIAL.md&show=terminal)

1. 點上面的按鈕，用你的 Google 帳號登入。Cloud Shell 會自動下載程式，旁邊也會出現教學。
2. 在終端機執行 `bash deploy.sh`。腳本會自動建立專案、連結帳單、啟用 Cloud Run 和 Firestore（代碼擂台的排行榜）、建置並部署。
3. 最後印出的 `https://tank-battle-….run.app` 就是遊戲網址。

如果還沒有帳單帳戶，腳本會提示你先到 console.cloud.google.com/billing 建立。AI Pro 的 Cloud 額度要依照 Google Developer Program 福利說明（developers.google.com/profile/help/benefits）領取，並加到帳單帳戶。建議在「帳單 → 預算與快訊」設一個 5 美元的提醒。

部署設定說明：

- `asia-east1` 是台灣彰化機房，延遲最低。
- 最多只開一台伺服器（`--max-instances 1`），因為房間資料存在記憶體裡，所有人必須連到同一台。
- 沒人玩時會自動關機、不計費。第一個人連進來時要等幾秒開機。
- Cloud Run 單一連線最長 60 分鐘。遊戲會自動重新連線，玩家不會被踢出房間。
- 更新版本時，在 Cloud Shell 執行 `git pull && bash deploy.sh`。

## 手機小技巧

- Android：開始遊戲時會自動全螢幕並鎖定橫向。
- iPhone：用 Safari 打開後點「分享 → 加入主畫面」，就能全螢幕遊玩。
- 橫向和直向都可以玩。橫向時地圖在中間、搖桿和開火鍵在兩側；直向時控制區在下方。
- 電腦上可以用方向鍵或 WASD 移動，空白鍵開火。

## 專案結構

```
server/
  index.js         HTTP + WebSocket 伺服器
  room.js          房間、大廳、多局比賽流程
  game.js          遊戲模擬（每秒 30 tick，伺服器說了算）
  mapgen.js        隨機地圖（2 隊與 4 隊時地形對稱）
  botRunner.js     玩家代碼沙盒
  validate.js      送出代碼前的測試對戰
  validateWorker.js  在背景執行緒做檢查，不卡遊戲
  spec.js          給玩家／AI 看的代碼規格
  defaultBot.js    範例代碼（也是內建電腦隊伍的 AI）
  constants.js     所有遊戲數值
  objectives.js    佔點、搶旗、護送
  pve/             打怪：資料（怪物、Boss、強化卡、關卡）、怪物 AI、Boss、流程
  pveBoard.js      打怪排行榜（無盡、每週挑戰）
  skills.js        職業技能
  terrain.js       特殊地形（油桶、補血站、傳送門）與縮圈
  codeHints.js     送出代碼時的相容性提醒
  samples.js       四種範例打法
  league.js        代碼擂台（Firestore 或記憶體）
  match.js         擂台對戰
public/            手機網頁（畫面、操作、編輯器）
  physics.js       伺服器和手機共用的移動物理（本機預測用）
  sfx.js           合成音效
test/              引擎測試與平衡模擬
```
