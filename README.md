# 坦克對戰

手機可玩的線上即時坦克對戰。每位玩家帶一台**用自己寫的代碼控制的電腦隊友**上場。玩家可以先跟自己的 AI 助手討論，再把寫好的代碼貼進遊戲。

## 玩法

- 輸入暱稱、建立房間，把 4 位數房號（或「分享」連結）給朋友，最多 6 人。
- 房主可以加入「電腦隊伍」湊人數或自己練習。
- 每位玩家有一台自己操作的坦克（3 條命）和一台代碼控制的電腦坦克（1 條命）。
- 沒有友軍傷害，但所有坦克之間都有碰撞。
- 每局結束後有調整時間：可以看自己電腦的錯誤和 `console.log`、修改代碼、換職業。房主決定總共打幾局。

### 模式（房主在大廳設定）

| 設定 | 說明 |
|---|---|
| 大亂鬥 | 每位玩家和自己的電腦一隊 |
| 陣營戰 | 紅藍兩軍 |
| 組隊 | 玩家自選 1～6 號隊伍，同號就是隊友 |
| 純代碼對戰 | 玩家不下場，每人只派一台電腦坦克，大家一起看 |
| 基地模式 | 每隊一座基地，被打爆就整隊出局 |
| 迷霧 | 玩家只看得到自己周圍；電腦不受影響 |
| 牆壁打不破 | 磚牆變成打不破，基地圍牆會留缺口 |

模式和開關可以自由組合，例如「組隊＋基地＋迷霧」。

### 職業（只有玩家坦克有，電腦固定為標準規格）

| 職業 | 移速 | 開火冷卻 | 彈速 | 特性 |
|---|---|---|---|---|
| 突擊 | 4.0 | 0.47 秒 | 12 | 場上可同時有 2 顆子彈 |
| 重裝 | 2.8 | 0.67 秒 | 10 | 每條命要被打 2 下 |
| 偵察 | 5.6 | 0.40 秒 | 12 | 最快；迷霧視野最大，看得穿草叢 |
| 狙擊 | 3.6 | 0.60 秒 | 24 | 子彈速度是別人的兩倍，迷霧視野較大 |
| 爆破 | 3.8 | 0.43 秒 | 12 | 子彈爆炸：炸毀 3×3 磚牆、波及周圍敵人 |

所有數值都在 `server/constants.js`，實際玩過之後可以再調。`node --no-node-snapshot test/balance.js 100` 會用範例 AI 跑一次平衡模擬。

### 電腦代碼

遊戲內「我的電腦代碼 → 規格」可以一鍵複製完整規格，貼給 AI 助手。規格只寫必要的事實（資料格式、地形、規則），策略留給玩家自己設計。代碼送出前，伺服器會用真正的遊戲引擎跑幾場測試對戰，確認能正常執行才會啟用。玩家代碼在隔離的 V8 沙盒（isolated-vm）裡執行，碰不到伺服器，無窮迴圈也會被逾時擋下。

## 在自己電腦上執行

需要 Node.js 20 以上。

```bash
npm install
npm start
```

打開 http://localhost:8080 。同一個 Wi-Fi 的手機可以用 `http://電腦IP:8080` 連進來。

測試：`npm test`

## 部署到 Google Cloud Run（用 Google AI Pro 的免費額度）

Google AI Pro 訂閱附有每月 10 美元的 Google Cloud 額度，Cloud Run 本身也有每月免費額度。以「沒什麼人玩」的用量來說，通常不會花到錢。

1. **領取額度**：依照 Google Developer Program 福利說明（developers.google.com/profile/help/benefits）領取 AI Pro 附帶的 Cloud 額度，並把它加到一個帳單帳戶。
2. **建立專案**：到 console.cloud.google.com 建立一個新專案，確認它連結到上一步的帳單帳戶。
3. **建議先設預算警示**：「帳單 → 預算與快訊」，設 5 美元提醒，比較安心。
4. **開啟 Cloud Shell**（主控台右上角的 `>_` 圖示），上傳這個專案的 zip 檔並解壓縮，然後執行：

```bash
cd tank-battle
gcloud run deploy tank-battle \
  --source . \
  --region asia-east1 \
  --allow-unauthenticated \
  --max-instances 1 \
  --min-instances 0 \
  --memory 512Mi --cpu 1 \
  --timeout 3600 \
  --session-affinity
```

第一次執行會詢問要不要啟用 API，全部回答 `y`。完成後會顯示一個 `https://tank-battle-xxxx.a.run.app` 網址，傳給朋友就能玩。

- `asia-east1` 是台灣彰化機房，延遲最低。
- `--max-instances 1` **一定要加**：房間資料存在記憶體裡，所有人必須連到同一台伺服器。
- 沒人玩時會自動關機、不計費。第一個人連進來時要等幾秒開機。
- Cloud Run 單一連線最長 60 分鐘。遊戲會自動重新連線，玩家不會被踢出房間。
- 更新版本時，重新執行同一行 `gcloud run deploy` 即可。

## 手機小技巧

- Android：開始遊戲時會自動全螢幕並鎖定橫向。
- iPhone：用 Safari 打開後點「分享 → 加入主畫面」，就能全螢幕遊玩。
- 橫向和直向都可以玩。橫向時地圖在中間、搖桿和開火鍵在兩側；直向時控制區在下方。
- 電腦上可以用方向鍵或 WASD 移動，空白鍵開火。

## 專案結構

```
server/
  index.js         HTTP + WebSocket 伺服器
  room.js          房間、大廳、多局比賽流程
  game.js          遊戲模擬（每秒 30 tick，伺服器說了算）
  mapgen.js        隨機地圖（2 隊與 4 隊時地形對稱）
  botRunner.js     玩家代碼沙盒
  validate.js      送出代碼前的測試對戰
  validateWorker.js  在背景執行緒做檢查，不卡遊戲
  spec.js          給玩家／AI 看的代碼規格
  defaultBot.js    範例代碼（也是內建電腦隊伍的 AI）
  constants.js     所有遊戲數值
public/            手機網頁（畫面、操作、編輯器）
test/              引擎測試與平衡模擬
```
